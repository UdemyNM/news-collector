手で打つと動くのに、AIエージェントやcronだと動かないのはなぜか。原因はPATH

Zenn

手で打つと動くコマンドが AI エージェントや cron で失敗する原因は、実行環境ごとに PATH が違うことだ。どのプログラムが動くかは呼び出した場所の PATH と shebang で決まるため、同じ php でも別の版が使われる。筆者は、WP-CLI が SSH の既定の古い PHP で動いて失敗した件を、絶対パスで呼ぶように直した。最初は Python のスクリプトを見落とし、失敗通知で気づいたという。失敗する環境で PATH と版を確認し、絶対パスで呼ぶか cron の PATH を先頭で決め、呼び出し元をすべて洗い出すことを勧めている。

v2.1.312（2026年10月27日リリース）は、主に修正と細かい改善のリリース。Claude apps gateway に oidc.user_id_claim が追加され、Microsoft Entra ID の oid のような sub 以外の ID クレームで利用者を識別できるようになった。ファイル書き込みや cd 後のスキル検出、セッション再開、PDF 読み込みなどの不具合が修正された。Bedrock・Vertex・Foundry・Mantle で未認識のモデル名に短いシステムプロンプトを使うようになり、使用制限の表示が「5-hour limit」に変わり、プロンプト／エージェント hook の同時実行数に上限が設けられた。
